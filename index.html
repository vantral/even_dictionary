Эвенский словарь

Спецсимволы:
Режим:

Обычный поиск по эвенскому заголовку с учётом диалектных вариантов.

О словаре

Поисковый интерфейс для эвенско-русского словаря с учётом некоторых особенностей быстринского говора.

Поиск и сортировка

Обычный
Ищет по эвенскому заголовку и ранжирует по точности совпадения. Начальный х не учитывается; эквивалентны с/ш, лл/лр, мн/мр и ӈр/ӈн.
По переводу
Ищет только в русском переводе. Обычный текст совпадает как целое слово или фраза; можно вводить регулярное выражение. Результаты идут по алфавиту.
Регулярное выражение
Применяет выражение только к эвенским заголовкам и сортирует найденные статьи по алфавиту.

Клик по заголовку открывает в новой вкладке выбранную статью и по 25 соседних статей с каждой стороны.

Источник данных

Роббек В. А., Роббек М. Е. Эвенско-русский словарь: свыше 14 000 слов. Новосибирск: Наука, 2005. 353 с. ISBN 5-02-032334-9.
